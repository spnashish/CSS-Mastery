2. CSS Box Model

Every element is a rectangular box with content, padding, border, and margin.

Box Model Demo
Width: 200px + Padding: 40px + Border: 6px = Total: 246px (content-box)
With box-sizing: border-box, total width = 200px

Box-sizing values:

  • content-box (default): Width/height only includes content
  • border-box (recommended): Width/height includes content, padding, and border

3. Flexbox Layout

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

Flex Container Properties

Item 1
Item 2 (flex-grow: 1)
Item 3

Key Flex Properties:

  • justify-content: Aligns items along main axis
  • align-items: Aligns items along cross axis
  • flex-grow: How much an item should grow
  • flex-shrink: How much an item should shrink
  • flex-basis: Initial size before free space distribution

5. CSS Positioning

Relative Positioning

Relative positioned element (moved 10px down, 20px right from normal position)

Absolute Positioning

Container with position: relative
Absolute positioned

Position Values:

  • static: Default, follows normal document flow
  • relative: Positioned relative to normal position
  • absolute: Positioned relative to nearest positioned ancestor
  • fixed: Positioned relative to viewport
  • sticky: Switches between relative and fixed

10. CSS Best Practices

  • ✅ Use box-sizing: border-box globally
  • ✅ Mobile-first responsive design with min-width media queries
  • ✅ Use CSS custom properties (variables) for consistent theming
  • ✅ Prefer rem and em units for scalability
  • ✅ Use semantic class names that describe purpose, not appearance
  • ✅ Animate transform and opacity for performance
  • ✅ Include prefers-reduced-motion for accessibility
  • ✅ Use :focus styles for keyboard navigation
  • ✅ Organize CSS with comments and consistent formatting
  • ✅ Test across different browsers and devices
