🎓 CSS Learning Navbar

📚 What You're Learning

This simple navbar teaches you the most important CSS properties:

Layout: flexbox, positioning, spacing

Styling: colors, fonts, borders, shadows

Interactions: hover effects, transitions

Responsive: mobile-friendly design

🔧 Try These Experiments

1. Change Colors: Find background-color and try different colors like red, green, or #ff6b6b

2. Adjust Spacing: Change padding and margin values to see how spacing works

3. Modify Hover: Change what happens when you hover over links

4. Add New Links: Copy a link in the HTML and add your own page

📖 Key CSS Properties Explained

display: flex - Makes items line up horizontally

padding - Space inside an element

margin - Space outside an element

position: fixed - Element stays in place when scrolling

:hover - Styles that apply when mouse hovers over element

transition - Makes changes smooth and animated

🎯 Challenge Yourself

Try making these changes to practice:

• Change the navbar background to your favorite color

• Make the hover effect a different color

• Add a new navigation link

• Change the font size of the links

• Make the navbar shadow more dramatic
